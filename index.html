Zoom in. It stays sharp.

  1. The whole world, at 1×

    257 countries and territories and 4,602 first-level regions in one file of 1.3 MB, 417 KB when the server compresses it. Each shape has its own ID: ISO 3166-1 for countries, ISO 3166-2 for regions, or Natural Earth’s own code for the 349 without a unique one.

  2. Southeast Asia, at 8×

    Malaysia’s states are tinted because they carry their own figures. Grey regions fall back to their country’s numbers, and say so.

  3. Peninsular Malaysia, at 16×

    Borders stay one screen pixel wide however far you go in, so outlines read as lines, never as smudges.

  4. Selangor, at 32×, chart open

    The chart panel is drawn in screen pixels, so it keeps the same readable size at every zoom level and on every screen.

Embed it in four moves

First, put the file on a page.

<object data="peta-dunia.svg"
        type="image/svg+xml"
        style="width:100%;aspect-ratio:2/1">
  World map
</object>
<!-- any JSON in the format below -->
<object data="peta-dunia.svg?data=/sales.json"
        type="image/svg+xml"></object>

{ "regions": { "MY-10": { "charts": [
  { "type": "line", "title": "Orders",
    "unit": "orders", "start": 2020,
    "values": [120, 180, 260, 410] }
] } } }
// from the page around the map
window.addEventListener("message", (e) => {
  if (e.data.type === "petadunia:select") {
    console.log(e.data.detail.id);   // "MY-10"
    console.log(e.data.detail.name); // "Selangor"
  }
});
const map = document.querySelector("object")
  .contentWindow.PetaDunia;

map.select("MY-10");          // open a chart
map.zoomTo("MYS");            // frame a country
map.load("/q3.json");         // swap the data
map.close();

Fair questions

  • Yes. blank.html is a blank page holding only the SVG. Click any region and its chart appears straight away, with no console errors, in Chrome, Firefox and Safari, opened from a server or straight from disk.

  • A region without its own figures shows its country’s, labelled as such. Where neither exists, the panel draws an empty chart that says so and names the ID to add. It never throws.

  • The map is one Tab stop. Arrow keys move to the nearest region in that direction, Page Up and Down jump between countries, and typing a name finds it. Enter opens the chart, Escape closes it.

  • Point the map at any JSON with a regions object keyed by the IDs in regions.csv. Each region holds a list of line or bar charts: a start year and values, or labels and values.

  • The brief asked for minimal dependencies. Two chart types and pan and zoom fit in 23 KB of plain JavaScript inside the SVG, so there is nothing else to load, update or break.

  • Natural Earth’s, which follow the boundaries in place on the ground. Disputed areas keep Natural Earth’s own codes. Swap the source data and rebuild if a client needs another view.
